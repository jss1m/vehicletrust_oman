# ملخص المشروع

VehicleTrust Oman نموذج بحثي للأمن السيبراني يميّز بين رقم اللوحة، وهوية قطعة اللوحة الفيزيائية، واستحقاق الرقم، وملكية المركبة، والربط النشط بالمركبة. يحمل الرمز الموقّع هوية ثابتة للوحة فقط، بينما تتحقق المنصة من المركبة عبر تحدٍ تشفيري جديد ومفتاح مستقل داخل وحدة آمنة محاكاة. يكشف النموذج تبديل اللوحات الأصلية، واستنساخ بيانات الاعتماد، والعبث، وإعادة الإرسال، ويُدير حالات الحجز والفقد والاستبدال والبيع والسرقة بسجل تاريخي قابل للتدقيق. جميع البيانات اصطناعية ولا يوجد اتصال بأنظمة شرطة عُمان السلطانية.
